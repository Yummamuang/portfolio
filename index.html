    About me

    Loop engineering

    A coding agent can work in a loop: it picks one task, automatic checks judge the result, and it stops when nothing is left to do. I design those loops: one change per pass, a gate that has to pass, and a rule for when to stop.

    1. 01Next item in STATE.md
    2. 02Fix a red gate
    3. 03Oldest PR comment
    4. 04Nothing pending: stop
    • One logical change per pass
    • Never edit a test to make it pass
    • Same item fails twice: stop and report

    Agent workflow

    How I split work for coding agents: a written plan, one fresh agent for each task, a review after every task, and one broad review of the whole branch at the end.

    1. 01Write the plan
    2. 02One subagent per task
    3. 03Review every task
    4. 04Review the whole branch
